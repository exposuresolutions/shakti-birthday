# Shakti Birthday Wishes

A one-page birthday quest game for Shakti (18 October 2026).

- `index.html` – standalone page, open it on a phone or host it anywhere.
- `artifact.html` – the same page without the document skeleton, used for the claude.ai artifact.
- `img/` – her photos (resized for the web).

Everything Dan can change lives in the `CONFIG` object at the top of the script:
restaurant name and menu, WhatsApp number, order countdown, bus stops, quests, and links/videos for La Leña.

Answers, orders and photo evidence are saved in the phone's browser storage and sent to Dan through
WhatsApp with the "Send" buttons.
